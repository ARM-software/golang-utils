func StripLeadingXMLHeaderComment

func StripLeadingXMLHeaderComment(data []byte) []byte

StripLeadingXMLHeaderComment removes a generated leading XML comment block when it contains the repository copyright or SPDX header markers.

This is intended for XML-like fixtures or serialised content where an automated header insertion step prepends a licence comment before the real document content. Comments that do not contain the recognised header markers are preserved unchanged.

func UnmarshallXML

func UnmarshallXML(data []byte, value any) error

UnmarshallXML unmarshals XML bytes into value.

It exists instead of using encoding/xml.Unmarshal directly because the decoder is configured with a charset reader, which allows non-UTF-8 XML encodings to be handled.
